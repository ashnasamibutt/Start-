# Start-
A beginner C++ practice repository where I learn and implement 
core programming concepts through small projects.

## Files
- **Main.cpp** _ Box class with operator overloading 
- **Evenoddcheck.cpp** _ Even and Odd number checker 
- **Student.cpp** _ Student class with getters, setters and constructors 

## Concepts covered
- OOP (Classes,Objects)
- Constructors (Default and Parameterized)
- Encapsulation (Getters and Setters)
- Operator Overloading
- Git and Github Basics
